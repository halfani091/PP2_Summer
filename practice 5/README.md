# Practice 5 — Python Regular Expressions (RegEx)

Парсер аптечного чека с использованием модуля `re`.

## Файлы

| Файл | Описание |
|------|----------|
| `raw.txt` | Исходный текст чека (EUROPHARMA, Нур-Султан) |
| `receipt_parser.py` | Парсер на RegEx |
| `receipt_output.json` | Результат работы парсера (генерируется) |

## Запуск

```bash
python receipt_parser.py
```

## RegEx-функции, использованные в коде

| Функция / конструкция | Где применяется |
|---|---|
| `re.search(pattern, text)` | Поиск метаданных, даты, итогов |
| `re.findall(pattern, text)` | Извлечение всех цен из текста |
| `re.split(pattern, text)` | Разбивка чека на блоки товаров, адреса |
| `re.sub(pattern, repl, text)` | Нормализация чисел, маскировка, очистка [RX] |
| `re.match(pattern, text)` | Определение строки кол-во × цена |
| `re.MULTILINE` | `^` срабатывает на каждую строку |
| `re.IGNORECASE` | Регистронезависимый поиск операций |
| Именованные группы `(?P<name>...)` | Структурированное извлечение данных |
| Квантификаторы `\d{2}`, `\d+`, `[\d\s]+` | Паттерны чисел и дат |
| Спецпоследовательности `\d \w \s \b` | Цифры, слова, пробелы, границы слов |

## Что парсится

- ✅ Название организации, БИН, номер чека
- ✅ Дата и время (`\d{2}\.\d{2}\.\d{4}`)
- ✅ Все товары: название, кол-во, цена за ед., сумма
- ✅ Флаг рецептурных препаратов `[RX]`
- ✅ Способ оплаты и итоговая сумма
- ✅ НДС
- ✅ Верификация: подсчитанная сумма = сумме в чеке
